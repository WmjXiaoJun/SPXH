# M3 验收报告：定时同步 + 载波跟踪 + 多体制解调 + 软判决 LLR

日期：2026-10-04  接收链标记：spxh-m3  版本：0.1.0

## 1. 范围与交付物

M3 把 M1/M2 的"参数估计 + 调制识别"接到真正的接收机结构上，输出**判决符号、比特与软判决 LLR**，
并把两条环路的收敛过程做成可观测量（前端"解调"页直接画出来）。

    spxh/core/demod/
      filters.py   三次拉格朗日（Farrow）插值器、AGC、可控分数延迟（测试用）
      sync.py      Gardner 定时环（二阶环路 + 插值）与判决导向载波环（二阶 PLL）+ 锁定指示
      llr.py       max-log 比特 LLR、噪声方差、星座旋转模糊阶数
      fsk.py       FSK 非相干音调检测与能量型软信息
      receiver.py  完整接收链：AGC -> 匹配滤波 -> 定时环 -> 载波环 -> 判决 -> LLR -> 误码对账
    scripts/check_m3.py   验收自检（BER 表 / 同步环价值 / LLR 校准 + 出图）

配套：CLI 新增 spxh demod；HTTP 接口新增 /api/demod（契约第 10 节）；前端新增第 5 个标签页"解调"。
测试从 227 项增至 245 项，全部通过。

## 2. 关键设计

### 2.1 为什么必须有跟踪环（M3 的存在理由）

M1 的因果曲线已经量化过：5.5 s 记录上，符号速率相对误差 1e-4 就把 EVM 从 10% 推到 19.5%，
残余载频 0.1 Hz 就把 BER 推到 0.21。也就是说**粗估精度根本不够长记录相干处理**，
必须由环路把残余吃掉。M3-B 的对照实验（同样注入 0.35 符号定时偏移 + 12 Hz 残余频偏）：

| 调制 | 无跟踪基线 BER | M3 接收链 BER | 改善 |
|---|---|---|---|
| QPSK | 4.95e-1 | 9.2e-4 | **537 倍** |
| 16QAM | 4.21e-1 | 1.0e-3 | **406 倍** |

### 2.2 环路观测量（可解释性的落点）

* **定时环**：Gardner 误差检测器 + 二阶环路 + Farrow 插值。中点必须取 sps/2 的偏移
  （固定 0.5 个样本只在 2 样本/符号时成立），S 曲线符号决定 mu 的更新方向。
  环路观测量：逐符号定时误差（归一化）。
* **载波环**：判决导向二阶 PLL，先用 M1 的粗估把残余压进捕获带。观测量：逐符号相位误差（rad）
  与**跟踪到的频偏（Hz）**。锁定指示用标准做法 |mean(exp(j*相位误差))|，锁定时接近 1。
* 两个环路都从匹配滤波峰值附近起步（2 倍滤波器群延迟）——从 0 附近起步会在滤波器暂态零区
  空转，既浪费时间又让归一化尺度失真（这是实测踩过的坑，见第 4 节）。

## 3. 验收结果

### 3.1 解调 BER（注入 0.35 符号定时偏移 + 37 Hz 频偏，全部由接收链自行纠正）

| 调制 | 0 dB | 5 dB | 10 dB | 15 dB | 20 dB |
|---|---|---|---|---|---|
| BPSK | 4.9e-1 | 6.5e-3 | **0** | **0** | **0** |
| QPSK | 4.8e-1 | 4.9e-1 | 2.7e-3 | 3.5e-4 | 9.2e-4 |
| 8PSK | 4.9e-1 | 4.2e-1 | 1.8e-1 | 2.5e-3 | 5.4e-3 |
| 16QAM | 4.9e-1 | 4.9e-1 | 2.9e-1 | 7.7e-3 | 1.0e-3 |
| 2FSK | 4.9e-1 | 1.1e-1 | 2.2e-3 | **0** | **0** |
| 4FSK | 4.8e-1 | 4.9e-1 | 2.8e-2 | 4.6e-4 | **0** |

20 dB 时的 EVM：BPSK 10.7%、QPSK 12.2%、8PSK 12.8%、16QAM 11.3% —— 纯噪声理论值约 10%，
说明接收链基本是噪声受限的；定时/载波收敛度 0.93~0.96 / 0.995 以上。

判据：SNR 不低于 15 dB 时 BER 不超过 1e-2（实测最差 7.7e-3），20 dB 时不超过 1e-2（实测最差 5.4e-3）。

### 3.2 LLR 校准（软判决能不能直接用的前提）

对 BPSK，若 LLR 定义为 log(P0/P1) 且标定正确，后验错误概率恰为 1/(1+exp(|LLR|))。
把"期望误码数"与"实测误码数"对账（高信噪比下实测为 0，因此用 1 作为置信下界）：

| Es/N0 | LLR 预测 p_err | 期望误码数 | 实测误码数 | 比值 | 判定 |
|---|---|---|---|---|---|
| 5 dB | 7.99e-3 | 69.5 | 69 | 0.99 | ok |
| 10 dB | 2.98e-4 | 2.59 | 0 | 0.39 | PASS |
| 15 dB | 2.34e-4 | 2.03 | 0 | 0.49 | PASS |
| 20 dB | 1.89e-4 | 1.65 | 0 | 0.61 | PASS |

5 dB 那行几乎完美（0.99），说明 LLR 的尺度可信 —— M4 的 Viterbi/LDPC 可以直接使用。

## 4. M3 期间发现并修复的问题

1. **Farrow 插值器系数写错**：最初的 a0~a3 展开不是三次拉格朗日基，插值误差 1e-2 量级。
   改成显式拉格朗日基，并加解析验证（插值复指数误差 < 1e-4）。
2. **Gardner 的中点取错**：写成固定 0.5 个样本的偏移（只在 2 sps 时成立），sps=8 时整个
   误差检测器失效。改为 sps/2，并用数值方法测出 S 曲线验证形状与符号。
3. **环路更新方向写反**：实测 S 曲线在采样偏晚时 e>0，因此 mu 应当**减小**；写成累加后
   环路直接发散（EVM 卡在 59% 不收敛）。
4. **从滤波器暂态零区起步**：定时环从位置 0 附近启动会在零区空转 100 多个符号，
   且把归一化尺度带偏。改为从 2 倍群延迟附近起步。
5. **归一化尺度不稳**：逐样本滑动功率会被暂态拉偏，改用全段平均功率（常数）。
6. **FSK 相关器多取了一次共轭**：等价于用 -f_m 去相关，2FSK 判决完全相反（BER 0.486，
   正好是"完美翻转"的特征）。去掉共轭后 BER = 0。
7. **载波环频率单位混乱**：积分器是"每符号相位增量"（rad/symbol），却被当作 Hz 上报，
   前端量纲错误。改为对外统一 Hz（并明确"与输入残余同号"的约定）。
8. **定时锁定指标没有信息量**：拿整段误差 RMS 当参考时，锁定与失锁的指标都约 0.2。
   改为固定尺度（实测标定），载波环改用标准的 |mean(exp(j*e))| 锁检测量。
9. **AGC 尺度与 LLR 尺度不一致**：AGC 在滤波器输出上做，符号样本功率有百分之几偏差，
   而 LLR 的 sigma 平方与 EVM 都假设判决点功率为 1。补上符号级增益归一化。
10. **LLR 校准检查的假失败**：高信噪比下实测误码数为 0，直接算比值会得到 0。
    改为比较期望误码数与观测误码数（0 用置信下界 1）。
11. **JSON 里的 Infinity**：锁定字段一度出现 Infinity，前端 JSON.parse 直接失败；
    统一改成 null（沿用 M2 的修法）。
12. **短记录的假失败**：早期用 3~4 帧（600~1100 符号）验收，捕获暂态占比过大，
    8PSK/16QAM 出现假失败；改用 8 帧 x 128 B（2000~8700 符号）后结果稳定。

## 5. 已知局限

- **Es/N0 低于 10 dB 时环路锁不住**：sps=8 时波形带内 SNR 比 Es/N0 低 9 dB，0 dB 的 Es/N0
  对应约 -9 dB 的波形信噪比。此时接收链 BER 接近 0.5，锁定指标也会下降（前端显示"临界/失锁"）。
  这是物理限制；改进方向是低信噪比下的前向估计（更长积累、非数据辅助的频偏/定时联合估计）。
- **存在约 1e-3 的误码地板**：QPSK 在 20 dB 实测 9.2e-4、8PSK 5.4e-3，来源是环路残余抖动
  （定时/相位），不是噪声。改进方向：更高阶插值、环路带宽自适应、2 样本/符号的经典 Gardner 实现。
- **相位模糊未在链内解决**：BPSK 180 度、QPSK/16QAM 90 度、8PSK 45 度是调制本身的性质，
  真实接收机用已知前导（本项目的 Barker-13 帧头，M5）或差分编码解决。当前在"与真值对账"时
  做旋转 + 符号滑动联合搜索，并在结果里明确报出用了哪个旋转，不掩盖问题。
- **FSK 的锁定指标恒为 1.0**：FSK 用非相干音调检测，不需要定时/载波环，这是设计使然，
  但前端"锁定"徽标对 FSK 不具信息量（已在设计说明中标注）。
- **4FSK 的符号速率估计在低信噪比仍不可靠**（M1 遗留），会连带影响解调（表现为符号数异常）。

## 6. 快速使用

    # 命令行解调（有真值会自动算 BER）
    python -m spxh demod data/demo/qpsk_snr+10.0_000.sigmf-meta

    # 验收自检
    python scripts/check_m3.py

    # 前端"解调"页（锁定状态、星座+判决区域、三条同步轨迹、LLR、BER）
    python -m spxh serve      # 浏览器打开 http://127.0.0.1:8760/ ，切到"解调"标签

Python API：

    from spxh.core.io import load_signal
    from spxh.core.demod import demodulate

    signal = load_signal("data/demo/qpsk_snr+10.0_000.sigmf-meta")
    result = demodulate(signal, modulation="qpsk")
    print(result.timing_metric, result.carrier_metric, result.evm_percent)
    print(result.bits[:32], result.llr[:8])
