# M2 验收报告：五域特征 + 调制识别（随机森林 + 校准 + 门控 + 物理回退）

日期：2026-10-04  分类器标记：spxh-rf-v1  版本：0.1.0

## 1. 范围与交付物

M2 把"未知 I/Q"变成"这是哪种调制 + 有多大把握 + 凭什么"。三层结构严格按方案落地：

1. **机器学习判决**：随机森林（按估计信噪比分区的专家）→ Platt 校准后的类别概率；
2. **置信度门控**：校准概率 < 门限，或特征向量马氏距离超阈值（分布外）→ 拒绝机器学习判决；
3. **物理规则回退**：确定性、可复现、可解释的规则；规则自己也没把握时 gate=reject，明确报"未知"。

新增模块：

    spxh/core/features/
      extractor.py       五域 23 维特征的唯一入口（顺序固定，模型里做校验）
      cumulant.py        C40/C42/C63/峰度（**在符号速率采样点上算**）
      spectral.py        带宽比、平坦度、峰噪比、滚降估计、谱偏度
      timefreq.py        STFT 帧功率方差、原始包络变异系数、谱质心游走
      constellation.py   盲符号恢复（定时分块搜索 + 残余载频去旋）+ 星座几何特征
      cyclostationary.py 循环谱线强度、谐波数、峰值/中位比、熵、谱线数
    spxh/core/classify/

      model.py           分区专家 + 校准 + OOD + 门控 + 训练
      pipeline.py        classify_signal：信号 -> M1 估计 -> 特征 -> 分类
    scripts/train_classifier.py   训练脚本（随机参数数据集）

CLI 新增：spxh features、spxh classify、spxh serve。测试从 179 项增至 227 项，全部通过。

## 2. 特征工程里的三个关键决定（都是实测逼出来的）

### 2.1 累积量必须算在符号速率采样点上

直接对过采样波形求高阶累积量会因为中心极限效应趋近 0：实测 BPSK 的 |C40| 只有 **0.007**，
而理论上应该是 2。改为先在盲恢复的符号点上计算后：

| 调制 | abs(C40) 实测 | 理论 | abs(C42) 实测 | 理论 | abs(C63) 实测 | 理论 |
|---|---|---|---|---|---|---|
| BPSK | 1.95 | 2.00 | 1.95 | 2.00 | 14.1 | 16.0 |
| QPSK | 0.97 | 1.00 | 0.98 | 1.00 | 5.39 | 4.0 |
| 8PSK | 0.03 | 0.00 | 0.98 | 1.00 | 5.19 | 0.0 |
| 16QAM | 0.66 | 0.68 | 0.68 | 0.68 | 4.25 | 2.08 |

（C63 因为 ISI 与噪声偏离理论，但**可重复**，分类器学的是实测分布而不是教科书门限。）

### 2.2 盲星座恢复必须做残余载频去旋

M1 的载频粗估误差约 1% Rs（1 kHz 符号速率下约 10 Hz）。在 0.3 s 的记录上这会累积几十弧度，
把星座转成一个圆环：实测 QPSK 的 |C40| 从 1.0 掉到 **0.03**、星座簇数从 4 涨到 **11**。
有意思的是 |C42| 不受影响，因为它只依赖幅度 —— 这正好说明问题出在相干积累上。

解法：s 的 M 次方的相位是 M 倍星座朝向加上 M 倍残余频偏，于是 |FFT(s^M)| 的峰值位置就是 M*Δf。
对 M 属于 {2,4,8} 取峰最显著者做一次**全局**去旋（不逐块去旋，避免 M 重模糊把星座簇打散）。
修复后簇数：BPSK 2、QPSK 4、8PSK 8、16QAM 17，与真实星座规模一致。

先试过的"分块相位 + 解缠"方案是错的：残余 10 Hz、块长 64 符号时每块漂 187 度，
远超 M 次方相位的 45 度解缠上限，必然解错。

### 2.3 特征替换：tf_burstiness -> tf_env_cv

原始包络的变异系数 std(|x|)/mean(|x|) 是最鲁棒的恒模判据：20 dB 时 FSK 约 0.19、RRC 成型
PSK/QAM 约 0.34~0.44。它取代了几乎没有区分度的 tf_burstiness。

## 3. 验收结果

### 3.1 分类精度、门控与校准（每格 10 个**全新随机参数**样本，共 300 个）

| SNR (dB) | 准确率 | gate=ml | gate=fallback | gate=reject | 走 ML 判决的错误率 |
|---|---|---|---|---|---|
| -5 | 0.300 | 0.150 | 0.733 | 0.117 | 0.111 |
| 0 | 0.567 | 0.450 | 0.433 | 0.117 | 0.148 |
| 5 | 0.650 | 0.717 | 0.233 | 0.050 | 0.116 |
| 10 | 0.900 | 0.933 | 0.067 | 0.000 | 0.071 |
| 20 | 1.000 | 0.967 | 0.033 | 0.000 | 0.000 |

SNR >= 5 dB：准确率 0.850，作答率（非 reject）0.983，**机器学习判决的错误率 0.057**，
全部样本 ECE 0.087。

SNR >= 5 dB 的混淆矩阵（行=真值，列=预测）：

    bpsk      28   0   0   0   0   0
    qpsk       0  19   4   1   0   6
    8psk       0   3  20   4   0   3
    16qam      0   2   1  26   0   1
    2fsk       0   0   0   0  30   0
    4fsk       0   0   0   0   0  30

剩余的混淆集中在 QPSK / 8PSK / 16QAM 之间（低信噪比下相位与幅度结构都被噪声糊掉），
这正是 AMC 的经典难点；BPSK 与两类 FSK 在全信噪比区间都是满分。

### 3.2 分布外检测

| 输入类型 | 被标记比例 |
|---|---|
| 纯噪声 | 1.00 |
| 2FSK h=0.25（训练分布外的调制指数） | 1.00 |
| 符号速率 80 Hz（远低于训练范围） | 0.375 |
| 16QAM 滚降 0.9（训练范围外） | 0.00 |
| **合计** | **0.594** |

结论：与训练分布**明显不同**的输入（纯噪声、异构波形）能被拦住；但"同一族、只是参数偏移"
（滚降 0.9）马氏距离并不敏感 —— 这是均值-协方差型 OOD 的固有局限，改进方向是加入
密度估计或重构误差，已记入后续工作。

### 3.3 物理规则单独表现（10 dB，6 类各 6 个样本）

    bpsk 6/6 | qpsk 3/6 | 8psk 3/6 | 16qam 4/6 | 2fsk 0/6 | 4fsk 4/6   总体 0.556

这个数字**不作为验收项**，因为它说明了一件更重要的事：把规则门限从 0.55 提到 0.70，
命中率反而从 0.556 掉到 0.417（规则只会"更少答"，精度几乎不涨）。**低信噪比下物理量本身
不可分**，靠调门限救不回来。因此规则的定位是：

* 提供**可复现、可解释**的第二意见（每一步打分都能说出依据）；
* 在低信噪比时**敢于拒答**，把"不确定"如实交给 gate=reject。

### 3.4 验收判据（全部通过）

| 判据 | 目标 | 实测 |
|---|---|---|

## 4. M2 期间发现并修复的问题

1. **过采样波形上没有累积量信息**：|C40| 0.007 vs 理论 2。改为符号速率采样后恢复。
2. **残余载频把星座转成圆环**：|C40| 1.0 -> 0.03、簇数 4 -> 11。用 M 次方周期图峰值搜索做全局去旋。
3. **"分块相位 + 解缠"在残余 10 Hz 时必然解错**（每块漂 187 度，远超 45 度上限）。
4. **全局单模型在低信噪比被拉平**：10 dB 准确率只有 0.75、ECE 0.16。改为按**估计 SNR**
   分区训练 3 个专家 + 各自校准后，10 dB 升到 0.90、ECE 降到 0.087。
5. **门限 0.7 太保守**：把大量判对的样本推给更弱的物理规则。改为 0.5（实测 ML 判决错误率 0.057）。
6. **特征 tf_burstiness 无区分度**：换成原始包络变异系数。
7. **Infinity 不能进 JSON**：snr_max 写成 Infinity 会让前端 JSON.parse 直接抛错
   （Python 的 json.dumps 默认允许 Infinity，JS 不允许）。所有信噪比上界改为 null。
8. **joblib 多进程在受限沙箱被拒**（命名管道 WinError 5）：随机森林改单进程训练。
9. **sklearn 版本间的特征重要度属性差异**：空列表求均值得到 0 维数组，zip 时炸掉；改为显式校验形状。
10. **API 工作区根目录算错一层**（parents[2] 而不是 parents[1]），导致接口全部 404。

## 5. 已知局限

- **0 dB 以下基本不可用**：这是物理限制，不是实现问题 —— sps=8 时波形带内 SNR 比 Es/N0 低
  10*log10(8) 约 9 dB，0 dB 的 Es/N0 对应约 -9 dB 的波形信噪比。此时系统主要靠"拒答"表达不确定。
- **2FSK / 4FSK 的规则子类判定不可靠**：两者的占用带宽比（约 2.9 vs 约 3.4）随符号速率漂移，
  瞬时频率音调数在低信噪比会漏检。
- **OOD 对同族参数偏移不敏感**（滚降 0.9 检出率 0）。
- **星座特征依赖滚降假设 0.35**：真实滚降不同会带来匹配滤波失配（v2 可做滚降盲估计）。
- 分类器只在合成数据上训练/测试；真实录波（多径、非线性、非白噪声）不在本轮验证范围内。

## 6. 快速使用

    # 训练（约 90 秒，1347 个样本）
    python scripts/train_classifier.py --out models --per-combo 45 --snrs=-5,0,5,10,20

    # 验收自检（精度/门控/校准/OOD + 出图）
    python scripts/check_m2.py --per-combo 10

    # 单文件识别与特征查看
    python -m spxh classify data/demo/qpsk_snr+10.0_000.sigmf-meta
    python -m spxh features data/demo/qpsk_snr+10.0_000.sigmf-meta

    # 前端工作台（浏览器打开 http://127.0.0.1:8760/）
    python -m spxh serve
