# M0 验收报告：信号导入 + 合成信号生成 + 真值闭环

日期：2026-10-04  生成器标记：spxh-m0  版本：0.1.0

## 1. 范围与交付物

M0 只做一件事：**让整条链路可验证**。合成器产生带完整真值的信号，后续每一级（参数估计 /
分类 / 解调 / 译码 / 帧同步）都能用真值量化误差，而不是靠肉眼判断星座好不好看。

交付物：

- 可安装的 Python 包 spxh（pyproject.toml，entry point: spxh）。
- 多格式 I/O：RAW（cf32/cf64/ci16/ci8/ci32/rf32/rf64/ri16）、WAV（I/Q 或实信号解析）、
  SigMF v1.0.0（含帧注解与真值摘要）、npz bundle。
- 帧结构层：Barker-13 前导 + 32 位帧头 + 载荷 + CRC-16-CCITT。
- 合成层：六类调制（BPSK/QPSK/8PSK/16QAM/2FSK/4FSK）、RRC 成型、AWGN/频偏/相位噪声/
  IQ 不平衡/DC 偏置。
- 真值 sidecar：比特流、符号索引、星座点、FSK 音调、帧边界、CRC、全部生成参数、无噪参考波形。
- CLI：generate / dataset / info / mods。
- 110 项 pytest 单元与端到端测试；M0 验收脚本 scripts/check_m0.py。

## 3. 关键约定

### 3.1 SNR 定义

10*log10(Es/N0)。Es 是**每符号波形的能量**：PSK/QAM 经单位能量 RRC 成型后 Es = 1；
FSK 恒模、每符号 sps 个采样点，故 Es = sps。复噪声方差
sigma^2 = Es / 10^(SNR/10)，I/Q 各分一半。该定义与 sps、调制方式无关，
可直接对应接收端匹配滤波后的 Es/N0。

实测校验：QPSK、目标 10.00 dB，实测噪声方差反推 Es/N0 = 9.94 dB（有限样本波动）。

### 3.2 采样索引约定

真值中的采样索引基于**上采样符号栅格**：符号 k 占据 [k*sps, (k+1)*sps)，
波形数组相对该栅格有 +filter_delay_samples 的偏移。因此：

    波形中的最佳采样点（成型 + 匹配滤波后） = k*sps + 2*filter_delay_samples

### 3.3 帧格式（MSB-first）

    [0:13]              Barker-13 前导                 13 bit
    [13:45]             32 位帧头                       4 byte
    [45:45+8L]          载荷                            L byte
    [45+8L:49+8L]       CRC-16-CCITT（大端）            2 byte

帧头 32 位：byte0 = 0xA5 包标识；byte1 = bit7-4 调制码 | bit3-2 编码码 |
bit1 交织标志 | bit0 保留；byte2-3 = 载荷长度（uint16 大端）。
CRC 覆盖帧头 4 字节 + 载荷。

CRC 标准向量已校验：CRC16-CCITT("123456789") = 0x29B1。

## 4. 验证结果

### 4.1 端到端（理想参考接收端：无频偏/相噪/失衡、理想定时）

参数：symbol_rate=1000 Hz，sps=8，span=16，2 帧 x 48 字节载荷，seed=20261004。

| 调制 | 30 dB BER | 20 dB BER | 10 dB BER | 0 dB BER | 30 dB EVM% | 帧 CRC |
|---|---|---|---|---|---|---|
| BPSK | 0 | 0 | 0 | 7.5e-2 | 3.16 | 通过 |
| QPSK | 0 | 0 | 0 | 1.6e-1 | 3.10 | 通过 |
| 8PSK | 0 | 0 | 3.1e-2 | 2.6e-1 | 3.09 | 通过 |
| 16QAM | 0 | 0 | 6.1e-2 | 2.9e-1 | 3.20 | 通过 |
| 2FSK | 0 | 0 | 2.3e-3 | 3.1e-1 | 不适用 | 通过 |
| 4FSK | 0 | 0 | 3.0e-2 | 3.3e-1 | 不适用 | 通过 |

要点：

- 30 dB 时 EVM 约 3.1%，与纯噪声理论值 3.16%（= 1/sqrt(Es/N0)）一致，
  说明成型/匹配/判决链没有引入额外系统性损伤。
- 10 dB 处的 BER 与理论吻合：QPSK Es/N0=10 dB（Eb/N0=7 dB）理论 BER ≈ 7.8e-4；
  8PSK ≈ 2.9e-2；16QAM ≈ 6e-2 —— 量级一致，说明 SNR 定义与星座归一化正确。

### 4.2 其它自检

- 帧结构：全部 6 类调制、含空载荷/连续多帧，parse_frame 均通过且 payload 与真值一致；
  任意单比特翻转（前导/帧头/载荷/CRC 位置）都被拒绝。
- Barker-13：非周期自相关主瓣 13、旁瓣幅值 ≤ 1（对 2/3/4/5/7/11/13 全部校验）。
- 可复现性：同 seed 两次生成，波形与比特流 bit-exact 一致。
- 噪声方差：实测 sigma^2 与 Es/N0 定义偏差 < 0.06 dB。
- 单元测试：110 项全部通过（python -m pytest）。

## 5. M0 期间发现并修复的问题（都是真实工程陷阱，记录备查）

1. **np.clip 对复数数组会按字典序比较并丢弃虚部**。整型 I/Q 写盘时
   np.clip(complex, -1, 1-1/fs) 会把超量程样本替换成实数边界值，虚部直接归零，
   表现为回读后星座被压扁。修复：实部/虚部分别裁剪。
2. **8PSK 的 Gray 映射必须是"循环"的**。用 const[i] = exp(2j*pi*gray(i)/8) 会让
   315 度与 0 度这两个相邻相位相差 3 比特；正确做法是让相位 p 上的比特标签取
   bin_to_gray(p)（等价于标签 i 落在相位 gray_to_bin(i)），此时相邻相位（含首尾环绕）
   恰好相差 1 比特。已加自动化测试：每个星座点的所有最近邻都必须只差 1 比特。
3. **收端必须使用与发端完全相同的 RRC 抽头**。参考接收端原先固定 span=8，而发端
   改为 span=16 后群延迟不一致（64 vs 32 采样点），采样点整体偏移 4 个符号，
   误码率瞬间变成 0.5（看起来像"调制器坏了"）。修复：把 span_symbols 写进真值，
   收端从真值读取。
4. **有限长 RRC 存在截断 ISI**。span=8 时 RMS ISI ≈ 1.6e-2（EVM 底噪 1.6%），
   span=16 时降到 ≈ 2.8e-3，且随 span 非单调（截断尾项的符号交替导致部分抵消）。
   默认 span 已从 8 提到 16；这是设计取舍而非 bug，已写入测试注释。

## 7. 已知局限与对后续阶段的影响

- SigMF 注解按帧的**符号区间**给出，相邻帧可能重叠最多 1 个符号（因为帧比特数通常不是
  每符号比特数的整数倍）。做逐帧统计时需要按比特边界而不是采样边界切分。
- 波形首尾各约 span/2 个符号的脉冲被截断，M1 做 EVM/星座统计时建议排除边缘符号。
- 参考接收端不做定时同步/载波恢复/均衡，只用于 M0 真值自检；真实链路在 M1/M3 实现。
