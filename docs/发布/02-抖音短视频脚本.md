# 抖音短视频脚本 · SPXH（射频信号分析平台）

> 形式：竖屏 9:16 录屏 + 字幕（建议纯录屏 + 配音，不用出镜；出镜只放在开头 3 秒做钩子）
> 时长：**75 秒左右**（抖音完播率甜区 60~90 s）
> 素材：`docs/发布/配图/01~12`（工作台截图），实际录制请用 OBS 或系统录屏直接录浏览器
> 核心爽点：**从"完全看不懂"到"读出 512 字节载荷"的全过程可视化**

## 四、拍摄 / 剪辑要点

1. **一定用真录屏**，不要用图片轮播。工作台本身有交互动效（缩放、拖动、加载），这是最能留人的部分。
2. 分辨率 1920×1080 录制，剪成 1080×1920；**关键数字区域裁切放大到 1.5~2 倍**，手机上看才清楚。
3. 提前把页面加载好（避免录到"加载中"），**每一级操作都真实点击**，别只切画面。
4. 配色本来就偏暗色科技风，**不要额外加滤镜**；字幕加浅色描边即可。
5. 配音：语速略快、句子短。数字之后**停 0.3 秒**给字幕留时间。
6. BGM：低调电子/科技感，音量压到 -20 dB 以下，别盖过口播。
7. 结尾 **不要**喊"点赞关注"，用"链接在评论区"更自然；评论区置顶放项目地址。
