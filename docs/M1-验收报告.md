# M1 验收报告：频谱/时频分析与参数估计

日期：2026-10-04  估计器标记：spxh-m1  版本：0.1.0

## 1. 范围与交付物

M1 的目标：把"未知 I/Q"变成一组**带置信度和证据**的参数（载频、符号速率、信噪比），
并把"参数估计误差会如何毁掉星座"这件事量化出来。M1 不做调制识别（M2）也不做定时同步（M3）。

新增模块：

    spxh/core/dsp/
      spectrum.py     Welch 双侧 PSD、噪声底、谱峰（抛物线插值）、占用带宽、频段功率
      timefreq.py     STFT 瀑布（Waterfall，含频率-时间剖面）
    spxh/core/estimate/
      types.py        Estimate：值 + 单位 + 置信度 + 方法名 + 证据字典
      cfo.py          载频估计（谱质心 / 谱对称性 / 边界中点 -> 中位数融合）
      symbol_rate.py  符号速率估计（循环自相关 + 包络剖面 + 锚定基频判定）
      snr.py          盲 SNR（解析谱方法 + M2M4 交叉校验）
      analyze.py      analyze_signal() 一次调用完成全部估计，并能与真值对账
    spxh/tools/plots.py  频谱图 / 瀑布图 / 误差曲线出图（matplotlib 可选依赖）

CLI 新增：spxh spectrum（PSD/瀑布导出、出图）、spxh analyze（估计 + 真值对账）。
验收脚本：scripts/check_m1.py（精度表 + 因果曲线 + 出图）。
测试：测试总数从 110 增至 179，全部通过。

## 2. 方法与关键设计决策

### 2.1 载频：不要取谱峰

RRC 成型信号的功率谱是**平顶**的，峰位会在平顶上随机漂移（实测用 argmax 当载频估计
误差可达几十 Hz）。M1 改用三个互补的谱域统计量，取**中位数**融合：

| 估计量 | 定义 | 适用性 |
|---|---|---|
| centroid | 残余谱（平滑 + 扣噪声底）的功率质心 | PSK/QAM 对称谱最稳 |
| symmetry | 令 A(k)=sum_i r[i]*r[2k-i] 最大的 k | 多音（FSK）只要音调位置对成就成立，不受各音调强弱不均影响 |
| edge_midpoint | 残余谱在 peak*0.25 处的左右边界中点 | 对 FSK 音调位置敏感 |

中位数融合可以自动踢掉两路失效时的离群值（例如 2FSK 用质心会因音调使用不均衡偏 14 Hz，
而对称性法偏 0.0 Hz，中位数取到后者）。

### 2.2 符号速率：循环特征 + 基频判定

* **循环自相关**：z[n] = mean_tau x[n+tau] conj(x[n])，谱线出现在 alpha = k*Rs。
  六类调制都有效 —— FSK 恒模、没有包络起伏，只有这项能给出强谱线（实测比包络法高 20 dB 以上）。
* **包络**：z[n] = |x[n]|^2 - mean，对 PSK/QAM 成型信号很强。
* **分段平均**：把记录按 50% 重叠分成最多 8 段平均 |Z|^2。单段循环周期图方差极大，
  短记录下低频谱底会冒出比真实线更强的伪峰。
* **局部基线**：峰值显著性相对**滑动平均基线**（默认 200 Hz 窗）计算，而不是全局中位数。
  循环剖面的低频谱底有 1/f 抬升，用全局中位数会把 60~500 Hz 的伪峰算成十几 dB 的"强线"。
* **锚定基频**：真实基频必然满足 anchor = k*f0（anchor 是最强谱线），因此候选只有 anchor/k；
  再用"谐波是否**连续**出现"打分，得分相同取更大频率（少切分优先）。
  这一步是必须的：任何"遍历所有候选、谁能解释最多峰"的打法都会把基频判到 anchor/3、anchor/4，
  实测符号速率直接错 75%~95%。
* **物理下界**：占用带宽 B 与符号速率同量级（PSK/QAM 约 B/(1+alpha)，MFSK 约 B/((M-1)h+2)），
  搜索下界取 0.25*B 以排除低频谱底伪峰。

### 2.3 盲 SNR：解析式，不需要调制类型

复高斯白噪声的双侧 PSD 是常数 N0 = sigma^2/fs，于是

    P_signal = mean(|x|^2) - N0*fs
    Es/N0    = P_signal / (N0 * Rs)

推导：成型后 P_signal = Es/sps，N0*Rs = sigma^2/sps，比值恰为 Es/sigma^2。
只需要噪声底和符号速率。实测偏差 < 0.2 dB（在 Rs 估计正确的前提下）。

M2M4（M2/M4 矩）作为交叉校验记录在证据里：它对**恒模**信号（2FSK/4FSK）准确（<1.5 dB），
但对成型信号（包络起伏）会系统性偏低，因此不参与融合。

## 3. 验收结果

### 3.1 估计精度（Rs=1234.5 Hz、CFO=43.7 Hz、8 帧 x 128 B）

| 调制 | SNR | Δcfo | ΔRs/Rs | ΔEs/N0 | 判定 |
|---|---|---|---|---|---|
| BPSK | 20 / 10 dB | -0.10 / -0.05 Hz | -1.9e-6 / -2.6e-5 | -0.01 / 0.00 dB | PASS |
| QPSK | 20 / 10 dB | +9.50 / +10.43 Hz | +5.1e-7 / -3.5e-5 | +0.02 / +0.06 dB | PASS |
| 8PSK | 20 / 10 dB | +0.37 / -0.15 Hz | +3.6e-5 / +1.1e-4 | +0.01 / +0.04 dB | PASS |
| 16QAM | 20 / 10 dB | -3.20 / -8.13 Hz | +8.8e-5 / -1.3e-4 | -0.01 / -0.01 dB | PASS |
| 2FSK | 20 / 10 dB | +0.01 / +0.01 Hz | +3.8e-6 / +3.0e-5 | -0.13 / 0.00 dB | PASS |
| 4FSK | 20 / 10 dB | -10.51 / -6.42 Hz | +5.2e-5 / +1.2e-4 | -0.16 / +0.02 dB | PASS |

判据（SNR >= 10 dB）：|Δcfo| <= 2% Rs、|ΔRs/Rs| <= 0.2%、|ΔEs/N0| <= 0.5 dB。
实测最差：**|Δcfo| 10.5 Hz (0.85% Rs)、|ΔRs/Rs| 1.3e-4 (0.013%)、|ΔEs/N0| 0.16 dB**。

SNR = 0 dB（此时波形 SNR 约 -9 dB，因为 Es/N0 要减 10*log10(sps)）：
6 个调制全部出现明显偏差，但 **6/6 都被低置信度标记**（符号速率置信度 0.00，
analyze 会给出"符号速率估计置信度低"告警）—— 这是设计目标：宁可说"不知道"，不给一个自信的错值。

### 3.2 因果曲线：同步误差 -> EVM/BER（QPSK，SNR=20 dB，5.5 s 记录）

符号速率相对误差：

| ΔRs/Rs | 0 | 1e-4 | 3e-4 | 1e-3 | 3e-3 | 1e-2 |
|---|---|---|---|---|---|---|
| EVM (%) | 10.0 | 19.5 | 55.8 | 122.1 | 130.9 | 138.0 |
| BER | 0 | 0 | 0.108 | 0.402 | 0.450 | 0.493 |

残余载频误差：

| Δf (Hz) | 0 | 0.1 | 1 | 5 | 20 | 100 |
|---|---|---|---|---|---|---|
| EVM (%) | 10.0 | 74.4 | 138.6 | 142.7 | 141.9 | 139.6 |
| BER | 0 | 0.206 | 0.477 | 0.506 | 0.503 | 0.500 |

结论（把原文第 8 章的定性说法量化了）：

1. **符号速率误差在记录内累积成定时漂移**：ΔRs/Rs=1e-4 时 EVM 从 10% 涨到 19.5%，
   3e-4 时误码率已经 10%。要在 5 s 记录上保持零误码，符号速率相对误差必须优于约 1e-4。
2. **残余载频误差在记录内累积成相位旋转**：即使只有 0.1 Hz 残余，5.5 s 内也会累积
   3.5 rad 相位，EVM 直接 74%。也就是说**M1 的粗估精度（约 1% Rs）本身不足以支撑长记录相干处理，
   必须由 M3 的载波跟踪环闭合残余**，这正是"粗估（M1）+ 跟踪（M3）"分工的量化依据。
3. 误差超过某个门槛后 EVM/BER 饱和（星座已经彻底糊掉），说明链路对同步精度的要求是
   **阈值型**而不是渐变的。

## 4. M1 期间发现并修复的问题（记录备查）

1. **RRC 平顶谱不能取 argmax**：峰位在平顶上随机漂移，实测误差几十 Hz。改为三统计量中位数融合。
2. **单段循环周期图方差过大**：0.33 s 的 QPSK 记录把 1000 Hz 判成 152 Hz。改为最多 8 段平均。
3. **峰值显著性不能用全局中位数做基线**：循环剖面低频有 1/f 抬升，伪峰被算成十几 dB 的强线。
   改为滑动平均基线（白化）后，长短记录都稳定命中真值。
4. **谐波评分天然偏向子谐波**：只要切分到 anchor/k，就能拿锚本身（m=k）白拿分。
   改为锚定 + 谐波必须连续出现 + 候选门限收紧到 8 dB。
5. **占用带宽被噪声残余撑大**：低信噪比下 1350 Hz 的信号被判成 5800 Hz。改为平滑 + 噪声残余去偏。
6. **符号速率搜索缺少物理下界**：低频谱底伪峰会被选中（977 Hz 判成 149 Hz）。
   改为 0.25*B 下界。
7. **"单方法可用"不等于"两法分歧"**：FSK 恒模时包络法本来就没有线，原逻辑把它当成分歧并把
   置信度打到 0.03。改为部分一致性 0.6。
8. **出图时残余谱的 log 假象**：对 (平滑谱-噪声底) 直接取 log，噪声区得到 -3000 dB 的梳状假象；
   改为相对残余峰值的 dB 并钳位到 -60 dB。

## 5. 已知局限

- **4FSK(h=0.5) 在 10 dB 时符号速率不可靠**：其循环谱线只有约 5 dB，低于噪声伪峰。
  当前行为是返回低置信度（<0.35）而不是硬编码答案。改进方向：M2 分类出 FSK 后，
  用**音调间隔**（4FSK 相邻音调间隔 = h*Rs）做调制感知的符号速率精估。
- **载频精度约 1% Rs**：够做捕获，不足以支撑秒级相干处理（见因果曲线）。M3 用 Costas/判决导向环闭合。
- **未做滚降系数盲估计**：M1 的 EVM 实验使用真值滚降；谱形（滚降）估计是 M2 的特征之一。
- **未做定时同步**：参考接收端仍是理想采样相位，真实定时恢复在 M3。
- 低信噪比（Es/N0 <= 0 dB）时符号速率/载频只能给低置信度结果，需要更长记录或先做匹配滤波积累。

## 6. 快速使用

    # 估计并打印（若有同名真值 sidecar，会自动对账）

    # 频谱 + 瀑布导出 + 出图

    # 验收自检（精度表 + 因果曲线 + 出图）
    python scripts/check_m1.py

    # 测试
